# 06: 追加实例且保留已有模拟状态

**Parent:** [场景级实例物性应用规格](../../scene-instance-app/spec.md)

**What to build:** 用户在已有物体运动、变形后追加实例，共同模拟从冻结状态继续；旧物体不被重置，新旧物体相互接触，任何准备失败都保留原模拟和显示。

**Blocked by:** [05：首个实例加入模拟并直接抓取](05-first-simulation.md)

**Status:** ready-for-agent

- [ ] 在完整物理步之间冻结已有模拟，保留同一时刻的位置、形变、速度、静止几何、物性与稳定标识；结束抓取并使在途抓取失效。
- [ ] 模拟内部准备候选共同资源并迁移状态，应用不读取或搬运粒子缓冲；不得将变形位置作为新的静止形状。
- [ ] 准备新实例绑定以及共享资源改变后的旧体改绑；在同一发布边界切换共同状态、全部必要绑定、新视图及关联，成功后才释放旧资源。
- [ ] 新体从校正后的源布局、零初速度加入；不暗移旧体避开重叠。新旧体及容器在共同状态中接触，仅渲染内容不碰撞。
- [ ] 成功自动运行并开启抓取；CPU、GPU、视图、旧体改绑或最新参数同步失败及取消时，旧体保持冻结、新体仅渲染、全局暂停且可重试。
- [ ] 保留模拟时钟账目和未消费小数时间，准备耗时不进积压；清除待执行单步请求，继续时不追赶或突然跳跃。
- [ ] 准备中允许编辑新旧物性，发布使用最新有效值；重算全场最严格固定步长，保持预算与原值，不泄漏资源或接受旧任务/抓取结果。
- [ ] 在应用边界逐阶段注入失败、取消和迟到结果；真实 WebGPU 下用已变形且有速度的 A 追加 B，在发布时比较 A 状态与静止参考、B 零初速，继续观察接触和各自形变，确认每实例仅一份表示。
- [ ] 与返回准备操作共用名单及会话语义；当第 07 票可用时验证多体返回、重新开始及取消追加后返回，不增加单体移除或单体暂停功能。

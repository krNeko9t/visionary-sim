# 08: 导出配置并重新关联源文件恢复

**Parent:** [场景级实例物性应用规格](../../scene-instance-app/spec.md)

**What to build:** 用户将准备配置导出为轻量 JSON，在新会话导入并重新选择源文件后恢复场景编辑与多实例名单；恢复停留准备状态，点击开始才准备模拟。

**Blocked by:** [06：追加实例且保留已有模拟状态](06-append-simulation.md)、[07：返回准备、重新校正并再次开始](07-return-preparation.md)

**Status:** implemented-awaiting-webgpu-acceptance

**Assignee:** Newton · gpt-5.6-sol medium（主 agent 审计、验收、提交）

- [x] 配置包含格式版本、三槽完整文件字节 SHA-256 和便于重选的文件名、全局校正、最新容器配置、物性覆盖及参与名单；实例以该源组合内的正 ID 关联。
- [x] 导出不包含源大文件、运行位置偏移、形变、速度或运行时模拟体标识；运行中导出也只保存准备配置。
- [x] 导入完整校验版本、字段和实例引用后才替换；源文件尚不可读时进入待关联流程，不部分应用或声称已恢复。
- [x] 三槽内容相同且结构校验通过才应用配置，文件改名或移动不影响；任一槽不同按新场景导入，不自动套旧校正、容器、名单或物性。
- [x] 内容指纹仅证明与保存时一致，不证明初始三件套同源；名称、大小和修改时间不代替内容匹配，路径不代替文件权限。
- [ ] 恢复后显示校正后的源布局，名单不表示模拟资源就绪；点击开始走整体准备与失败保留路径，验证多实例恢复后共同模拟。
- [x] 损坏、未知版本或无法对应的实例引用有明确反馈，当前场景和编辑保留；不建立通用迁移、多项目或持久派生缓存。
- [ ] 应用边界覆盖格式及匹配反例；真实浏览器完成下载、导入、重选改名同内容文件、同名异内容文件和无缓存恢复，记录实际结果。

# 07: 返回准备、重新校正并再次开始

**Parent:** [场景级实例物性应用规格](../../scene-instance-app/spec.md)

**What to build:** 用户返回准备后恢复全局校正后的源布局，保留编辑成果和参与名单；可重新校正，再按名单开始模拟，旧状态和过期任务不会残留。

**Blocked by:** [05：首个实例加入模拟并直接抓取](05-first-simulation.md)

**Status:** implemented-awaiting-webgpu-acceptance

**Assignee:** James · gpt-5.6-sol medium（主 agent 审计、验收、提交）

- [ ] 返回准备终止演化和抓取，使任务失效，释放模拟及绑定资源；清零速度与模拟时钟，恢复源布局及未变形表示。
- [x] 保留源引用、实例身份、物性覆盖、参与名单、全局校正和最新容器配置；不保留另一份运行前容器快照。
- [x] 运行时重新校正或编辑容器先走返回准备，随后沿同一编辑入口修改；不额外增加含义不同的 reset 流程。
- [x] 开始操作按参与名单准备整批候选，完成必要模拟和显示准备后整体发布并运行；失败或取消保持准备状态和配置，不发布部分名单。
- [x] 流程接受任意实例名单，首版不提供单体退出、删除或单体暂停；不以新逐体状态管理绕开共同模拟内核。
- [x] 会话缓存由源内容、相关参数和策略版本决定复用，尺度变化使长度相关体积、质量等结果失效；无缓存仍可重建，资源不足可释放可重建缓存，仍失败则明确反馈。
- [ ] 应用边界验证返回、修改尺度、再次开始、失败保留和迟到任务；真实浏览器验证源布局恢复、新尺度模拟及最新容器保留。
- [ ] 用多实例名单验证整批开始；第 06 票可用时补验实际追加后的名单和状态清理。该票不依赖追加接口，可从单实例及名单开始路径独立完成。

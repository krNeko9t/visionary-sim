# 03: 选择实例并检查、补齐物性

**Parent:** [场景级实例物性应用规格](../../scene-instance-app/spec.md)

**What to build:** 用户在完整场景或列表中选择实例，通过着色检查对应关系，并查看、补齐或覆盖物性。缺失物性的实例保持可见，参数有效后具备加入条件。

**Blocked by:** [02：三文件导入并显示完整场景](02-import-scene.md)

**Status:** implemented-awaiting-webgpu-acceptance

**Assignee:** Ohm · gpt-5.6-sol medium（主 agent 审计、验收、提交）

- [ ] 场景点选与列表选择共用选中项；显示源场景内的稳定正 ID 和名称，不使用列表下标或名称作为身份。
- [ ] 提供实例着色核查，保留未追踪内容；明确结构校验无法自动证明同规模三件套同源，发现错配可重新选文件。
- [x] 分别显示上游原值和当前有效覆盖值，密度、杨氏模量及泊松比采用明确 SI 单位，不截断到演示滑块范围或静默软化。
- [x] 缺字段或整条物性记录时指出待补项；补齐并通过现有材料有效性约束后更新加入资格，其他实例不受影响。
- [x] 上游不确定性字段不冒充 SI 误差条，trust 不冒充准确性证明；不虚构标签 0 的物性或模拟身份。
- [x] 选择和编辑只更新应用状态及配置，不生成模拟资源；运行时参数应用由第 05 票接通。
- [ ] 应用公开操作覆盖选择、覆盖、非法值及补齐；真实浏览器检查遮挡、floater、列表选择和相机事件归属，记录实际结果。

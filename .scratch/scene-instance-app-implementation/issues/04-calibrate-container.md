# 04: 全局校正与场景容器编辑

**Parent:** [场景级实例物性应用规格](../../scene-instance-app/spec.md)

**What to build:** 用户在准备阶段校正完整场景的上轴、朝向、米制尺寸和位置，并用同一 gizmo 与数值入口编辑六面场景容器；场景和容器关系可见且保持一致。

**Blocked by:** [02：三文件导入并显示完整场景](02-import-scene.md)

**Status:** ready-for-agent

- [ ] 参考中心和最长边来自准备后保留的全场景有效高斯中心；默认最长边 1 米，尺度必须有限且大于零，不暗示测得真实尺寸，不自动落地。
- [ ] 六个上轴预设、固定世界轴 X/Y/Z 手工旋转、等比尺度和中心平移遵循规格的绝对配置约定；从源参考重算，反复编辑无累积漂移。
- [ ] 切换预设保留手工角、尺度和平移；选择实例及编辑容器不重算场景基准。空、非有限或零跨度场景明确阻止开始模拟。
- [ ] 高斯中心、轴向、尺度和方向相关外观一起变换，拾取与显示一致；SI 物性数值不随几何尺度修改，长度相关派生结果失效。
- [ ] 网格固定世界 Y=0 且不碰撞，相机 up 为世界 +Y；观察相机及世界重力不乘场景校正。
- [ ] 初始六面容器包围完整场景，全局校正带动容器；独立平移、旋转和三轴尺寸编辑不移动或缩放实例。gizmo 与数值输入共同修改一份位置、正交朝向和有限正内部尺寸。
- [ ] 初始越界或独立编辑后越界明确提示，不静默移动源场景适配；容器显示不妨碍观察，gizmo、相机与实例选择事件不冲突。
- [ ] 验证 2×1×0.5 的参考范围在 L=1 时对应 1×0.5×0.25；六预设正确、恢复配置无漂移、容器随动且不改变参考基准。真实浏览器验证直接编辑体验。
- [ ] 本票完成准备编辑；真实六面接触及抓取限域由第 05 票接通，运行时容器保持静止。

# 05: 首个实例加入模拟并直接抓取

**Parent:** [场景级实例物性应用规格](../../scene-instance-app/spec.md)

**What to build:** 用户将首个物性有效实例加入模拟后即可观察其运动、形变并直接抓取；其余场景保持仅渲染，容器六面约束运动，准备失败保留原显示。

**Blocked by:** [03：选择实例并检查、补齐物性](03-inspect-materials.md)、[04：全局校正与场景容器编辑](04-calibrate-container.md)

**Status:** implemented-awaiting-webgpu-acceptance

**Assignee:** Galileo · gpt-5.6-sol medium（主 agent 审计、验收、提交）

- [x] 仅为加入实例按需准备表面占据、体积、晶格、模拟资源和形变绑定，CPU 准备在适合的 Worker 任务中执行；不把真实厚度作为额外输入前提。
- [x] 二维椭圆片与体素相交覆盖复用既有封缝、填充和晶格流程，保留显示中心所在格占据；不将覆盖容差宣称为物理厚度，不用零半轴执行旧除法判定。
- [x] 近似质量为密度乘占据体积；以倾斜、薄表面和 bench 实例检查覆盖、漏填、误封及分辨率变化，不用有限正质量冒充真实质量验证。
- [ ] 模拟及显示全部准备成功才发布稳定模拟体关联与唯一可见表示，随后自动运行并开启抓取；发布前失败或取消保持静态可重试，并清理候选和迟到结果。
- [ ] 支持全局暂停和抓取开关；世界重力为 (0,-9.81,0)，容器局部接触和形变回世界一致，顶面在内的六面及旋转容器均有效，抓取目标限制在容器内部。
- [x] 模拟期间容器和全局校正不可直接编辑；仅渲染内容不参与碰撞。返回准备入口由第 07 票交付。
- [x] 运行、暂停及准备期间可编辑物性，不重置位置、形变和速度；提交前同步最新有效参数，非法最新值不发布。
- [x] 沿用共同固定步长与每帧 24 步预算，显示模拟慢于现实时间及丢时，不放大步长、不软化材料、不添加预算面板。准备耗时不计积压，失败或取消保持暂停。
- [ ] 应用边界验证准备、发布、取消及物性变化；真实 WebGPU 验证两轴形变、六面和旋转接触、摩擦、抓取限域及 UI 事件归属，既有演示回归通过。

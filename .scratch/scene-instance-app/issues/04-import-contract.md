## Question

决定本应用选择源场景和上游结果之后的准备契约（专属此上游，不设计跨应用通用格式）：

- 所需文件与匹配验证、标签过滤顺序、背景保留和稳定的实例标识；错误文件或不完整物性如何呈现。
- 按[两轴高斯表面怎样显示并成为可模拟的实体](10-surface-to-volume.md)的结论，明确两轴输入的准备产物及实际准备失败的反馈；不因 2DGS 或缺少真实厚度预先拒绝实例。
- 准备阶段先做哪些工作，哪些留到用户点击转模拟时才执行；进度、取消、失败重试与资源释放的含义。
- 选择何种浏览器能力基线、输入方式和 Worker / 缓存分工；如何避免为所有实例预分配模拟资源。

默认所有实例仅渲染，完整场景的相对布局须保留。列出正常路径与数据错误的验收例子；不把读取本机绝对路径作为网页能力。

## Answer

2026-09-09 · 用户确认导入入口、匹配检查、物性不完整处理及按需准备四项取舍。本票完成准备契约决策，不实施功能。

### 输入与校验

- 首版以桌面 Chrome/Edge 为验证目标，启动时检测项目所需 WebGPU 等能力，能力不足则给出明确原因；浏览器品牌不代替运行能力检查。提供三个明确文件槽，分别选择源 `point_cloud.ply`、`labels.npz`、`instance_physics.json`，全部在前端处理。目录自动查找暂缓，不以本机路径字符串获取文件访问权。
- 先解码并在原始 PLY 行序上校验，再进行任何筛选或重排。按本次核验的上游契约检查必要字段、数组类型和长度、labels/valid 关系、实例 ID 唯一性以及可用的 `n_gau` 与标签计数。文件损坏、长度错配、重复物性 ID 或明确矛盾的关联信息拒绝本次导入，并指出文件和原因。
- 单实例物性行或参数缺失属于可修复的实例问题，不等同于整套文件结构损坏。保留其显示与点选，标出缺失或不合法字段；用户补齐有效物性后才可加入模拟。不凭空填入默认值，也不影响其他物性完整的实例。
- 结构检查通过即允许继续，不要求先修改上游补充哈希。现有文件不能证明同规模数据未被错换或重排，界面不宣称已验证同源；提供实例着色检查，发现错配后可重新选文件。后续生成的缓存指纹也不能倒推证明本次三件套本来同源。

### 场景与实例对应

- 保留完整场景的共同坐标及相对布局。标签 0 表示未追踪内容，`valid=false` 不表示无效几何；两者都不是删除显示内容的依据。未追踪内容仅渲染，不虚构为有物性的正 ID 实例；墙、地板等正 ID 与其他实例一致处理。
- 稳定实例标识沿用上游正整数 ID，并限定在对应源场景内；名称、列表位置或模拟体下标不充当身份。标签先对应原始高斯行；任何后续筛选或重排必须同步携带这一映射，不能清洗 PLY 后再按旧下标贴标签。计数校验使用清洗前的数据。
- 本票不新增透明度、尺寸或实例大小的过滤阈值；不将现有逐云清洗和逐实例居中、缩放、落地流程直接套到完整场景。无法安全解析或显示的几何须报告具体原因，不能静默破坏实例对应。

### 准备产物与任务行为

- 导入阶段生成完整场景的两轴渲染数据、原始行到实例的对应、供点选与着色使用的索引、实例目录及物性校验结果。初始没有模拟体；不为全部实例预分配体素、晶格或求解资源。
- 用户加入实例时才执行该实例的表面占据、既有封缝填充流程、模拟资源及形变绑定准备。沿用已决的 2DGS 路线，不因缺少第三轴或真实厚度预先拒绝。加入时的暂停、速度、时钟和具体提交接口归生命周期票。
- 文件解码、关联检查和适合后台执行的 CPU 准备由应用专属 Worker 任务承担；UI 负责展示阶段、可获得的计数和取消入口。无法计算总量的阶段显示阶段状态，不伪造精确百分比；GPU 资源仍由创建它们的模块管理。
- 取消使当前任务结果失效，终止或协作停止后台工作并释放本次临时资源；迟到结果不能提交到新任务或新会话。失败显示所处阶段和具体原因，允许修正文件或参数后重试，不自动重复失败任务。
- 导入失败或取消不发布半成品场景；已有场景存在时保持原场景。实例加入失败或取消时，原实例保持仅渲染，已有模拟状态不受损。旧资源的具体保留与提交沿用应用分工票，实际内存压力交测量判断，不承诺同时容纳两套大场景。
- 本票只规定当前会话的准备及临时资源。跨会话派生缓存、配置保存、文件重新关联和失效策略由保存恢复票决定；缓存不能成为首次导入的必要条件。

### 验收例子

- 给定 bench 三件套通过结构检查后，完整场景可见，九个正 ID 实例可区分、点选和查看物性，标签 0 内容仍显示；尚未加入实例时模拟体数为零。
- 换入长度不同的 labels 文件时拒绝本次导入，报告不匹配的数量，不覆盖已有场景；同规模错换文件不宣称能够自动检出，可通过实例着色核查。
- 去掉某实例的密度字段或整条物性记录时，该实例仍可见，显示待补字段且不能加入模拟；补齐有效参数后可重试，其他实例不受影响。重复 ID、可用计数冲突等结构矛盾仍拒绝导入。
- 加入一个实例才为它生成体素与模拟资源，其余实例保持仅渲染；实际体素化失败时显示原因并保留原显示。
- 解析途中取消后重新选择文件，旧任务即使晚到也不改变新场景；失败及取消产生的临时资源得到释放。

上述为后续实现的验收要求，尚未运行浏览器导入、性能或模拟验证。本票未暴露需要另建的明确决策票；保存恢复、加入生命周期及完整流程验证继续由现有子票承担。

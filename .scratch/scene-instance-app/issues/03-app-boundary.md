### 讨论中的分工检验（过程记录，以 Answer 为准）

| 场景 | 应用承担 | 内核及渲染承担 | 检验点 |
|---|---|---|---|
| 导入后尚无模拟体 | 保存实例信息和准备配置，组织导入与展示 | 应用专属准备模块解析输入，渲染展示静态内容，模拟支持空集合 | 显示场景不以创建模拟体为前提 |
| 椅子已运动，再加入桌子 | 发起请求、显示进度、维护实例与模拟体关联 | 模拟模块离散化、调整资源并保留已有物理状态；经 deformation 接入渲染 | 应用不读取或搬运粒子缓冲；新增接口仍待实现 |
| 桌子准备失败 | 显示原因和重试入口，只在成功后标记参与模拟 | 保留已有模拟状态与显示资源，清理失败资源 | 需准备与提交契约，不让 UI 修补部分成功的状态 |
| 重置或回到准备阶段 | 决定保留哪些配置，说明重置范围 | 执行物理重置或资源释放，渲染同步更新 | 具体保留项由生命周期票确定 |

### 职责与接口

| 模块 | 拥有与负责 | 对外接口要求 |
|---|---|---|
| 拟新增 application/ | 应用会话、实例目录、选中项、准备配置、实例到模拟体及视图的关联；组织文件读取、Worker 任务、配置保存及恢复 | UI 接收状态与操作回调；不向 UI 暴露求解存储。任务结果必须属于当前会话，过期结果不能提交 |
| 具体应用内部的数据准备模块（拟放 application/ 内） | 上游格式读取、字段与单位解释、实例对应校验、转换及准备策略；随具体上游演变 | 以对应上游生产代码为依据，将输入转换为内核需要的几何与物性；Worker 执行该模块。各应用无需统一源文件或准备产物格式 |
| assets/ | 保留现有能力；仅复用已证实适用、无上游语义的基础函数 | 不接管所有应用的数据准备，不建立统一导入框架；基础解码与上游字段解释分开，不能因复用而强迫其他应用适配 |
| body/ | 准备后物体的材质、模拟几何与渲染几何描述 | 不依赖实例选择、文件权限或 UI；几何构建策略由后续票决定 |
| sim/ | 模拟体、离散化、粒子与约束、共同演化状态、模拟资源生命周期 | 沿用步进、材质、抓取、形变、重置与销毁入口；扩展准备/加入能力，失败不破坏旧状态；向应用提供不透明的稳定模拟体标识，内部下标变化不泄漏 |
| render/ 与 deformation/ | 可见资源及形变表达、绑定 | 静态与模拟表示通过同一形变通道接入；扩展可控的视图准备、替换与释放，资源替换失败保留旧视图 |
| ui/ | 文件选择控件、面板、进度和交互事件 | 新应用 UI 通过回调发起操作；已有 demo UI 可沿用当前模拟公开入口 |
| scene/ | 既有场景数据、观察环境、相机与装饰 | 保留现有 demo 配置；不承载新应用的导入与会话流程 |
| main.js | 选择并启动具体应用 | 将具体装配搬到 application/ 的 demo 与实例应用入口，不建设插件注册框架 |

所有权约束：应用决定何时发起操作，创建资源的模块负责释放及局部失败清理。应用负责跨模拟与渲染协调：先完成可失败的准备，保留旧状态与旧视图，待必要资源均就绪后再发布新关联和显示状态；不能先删除静态桌子再等待模拟准备。完整提交机制、暂停/速度/抓取/时钟规则由生命周期票落实；本票只确定责任和必须满足的失败契约。

零模拟体仍可显示、选择和校正场景，不要求放入虚拟物体；模拟入口已有空集合处理，完整空场景显示还需后续验证。实例标识属于上游场景，模拟体标识属于当前模拟会话，两者由应用关联，重建会话不把运行时标识写作持久身份。

拟议依赖变更：新增 application -> scene/assets/body/sim/render/ui；main.js -> application。下层不反向依赖 application；render -> deformation 的既有约束保留。新应用通过回调接 UI，不要求 ui -> application。这里仅为未来实现提案；真正新增目录时同步 ARCHITECTURE.md §二、architecture.test.js 的 ALLOWED/REQUIRED，并按仓库约定将理由追加 DECISIONS.md。

验收反例：新文件格式不应改求解器；替换离散化不应改应用流程；新增第二个模拟体不能要求应用搬运粒子缓冲；模拟或渲染准备失败不能让原实例消失；两个 demo 和新应用复用相同模拟/形变/渲染实现。首版单体退出模拟的取舍留在生命周期票，本票不把它作为必备接口。

补充检验：上游只改文件名、字段布局或编码时，应集中修改该应用的数据准备，不影响其他应用及求解器。若上游引入内核尚不能表达的几何或物理语义，则应显式评估内核能力，不承诺任何变化都能仅靠转换解决，也不能为了兼容而静默丢失语义。研究票已记录的文件契约只是本次所核验上游代码的快照，不是长期通用格式标准。

## Answer

2026-09-09 · 用户通过两轮交流确认尺度、支点、朝向与重置规则，本票解决。以下数学与数据同步约定将已确认行为具体化，供后续实现和验收；本次未实现功能。

### 尺度与支点

全场景统一等比例归一化，最长边为 1，默认代表 1 米；用户可设置最长边的米数 L（必须有限且大于 0）。首版不做两点测距。这里的 0–1 指尺度归一化，不要求放置后的所有世界坐标都落在 [0,1]，不允许三轴分别拉伸或逐实例归一化。默认 1 米是人为设定，不能视为恢复了真实尺寸。

参考包围盒取导入准备后保留的全场景有效高斯中心，包括仅渲染内容；不在本票另加分位数裁剪。以其中心 c 为旋转与缩放支点、最长边 d 为尺度基准。选中实例变化、加入模拟、碰撞盒编辑均不重算 c 或 d。空场景、非有限范围或 d=0 不允许开始模拟；输入清理和映射完整性仍由导入票负责。高斯自身尺度随同缩放，但不把高斯支持范围当成已知实体体积。

rho（kg/m³）、E（Pa）与 nu 不随几何尺度换算而改数值；几何变大时，体积及相应质量改变。改变 L 后需重建依赖物理长度的模拟准备结果，不能沿用旧体积或质量。

### 变换契约

世界使用右手系、Y 朝上、米作为长度单位，重力默认 (0,-9.81,0) m/s²。上轴预设表示源几何的方向，不表示相机坐标或软件品牌；首版不提供含糊的 Blender / Nerfstudio / OpenCV / OpenGL 名称预设，不根据名称猜测手性。左手输入若存在，由对应上游的数据准备明确转换，不能靠上轴选项假装解决镜像。

列向量约定下：`p_world = t + (L/d) R_manual R_preset (p_source - c)`。t 是校正后场景中心的世界位置，初始为原点；不隐式落地，用户通过平移对齐。预设采用右手主动旋转：+Y 为单位阵，-Y 为 Rx(180°)，+Z 为 Rx(-90°)，-Z 为 Rx(90°)，+X 为 Rz(90°)，-X 为 Rz(-90°)。它只定上轴，朝前方向由手工旋转调整。

手工角度采用固定世界轴，按 X、Y、Z 顺序应用，矩阵为 Rz·Ry·Rx。角度与预设均为绝对配置，从原始参考数据重算；切换预设仅替换 R_preset，保留手工角度、L 和 t。需要重新微调时将手工角度归零。旋转不重新计算归一化倍率，因此旋转后世界轴对齐包围盒最长边未必仍是 L；L 始终指参考包围盒的最长边长度。

### 显示、模拟与碰撞的一致性

- 高斯中心、轴向/法线与自身轴长同步转换；三轴表示可写作 covariance_world = s² R covariance_source Rᵀ，两轴表示保留其原有维度，不由本票补厚度。
- 方向相关外观必须与几何一起转向：可将世界观察方向逆旋转回源空间评价外观，或等价旋转其方向表示，不能只旋转中心和椭球。
- 模拟代理在同一校正世界生成，形变绑定、拾取射线及命中结果都使用一致空间。代理厚度及体积依据由「两轴高斯表面怎样显示并成为可模拟的实体」决定。
- 相机是世界空间观察工具，重力也固定在世界中，两者不乘场景校正矩阵。自动取景如有需要只调整观察位置，不改变物理尺寸；旧 demo 的固定容器范围不能当作新场景边界。
- 碰撞盒保存相对场景参考空间的姿态和尺寸；在当前世界新建或编辑时逆变换回参考空间。校正从 T_old 改为 T_new，盒的世界几何等价应用 T_new·inverse(T_old)，中心、朝向和尺寸一起变化。正的统一尺度保证盒仍是正交盒。盒不参加场景尺度基准的计算，碰撞使用与显示一致的世界几何。

### 返回准备阶段

正在模拟时不得直接改全局校正。返回准备阶段后终止当前抓取与演化，丢弃运行中的位置偏移、形变和速度，恢复各实例的源参考布局与未变形表示，再应用当前全局配置。保留数据引用、实例身份、参与模拟的选择、物性覆盖和碰撞盒编辑结果；随后允许修改校正。下次开始模拟重新准备所选实例，不把旧运行时状态旋转缩放后继续跑。暂停、时钟与重新加入的完整流程由生命周期票细化。

### 验收样例

1. 参考中心范围为 2×1×0.5，L=1 米，校正后对应边长为 1×0.5×0.25 米；任意两个实例中心距离都缩小一半，不能各自居中。将 L 改为 2 米，全部几何和盒尺寸翻倍，物性数值不变。
2. 手工角为零时，六个预设各自把选定源上轴映到世界 +Y；其余轴保持正交且行列式为 +1。连续两次选 +Z 与只选一次完全相同；默认重力仍为世界 -Y。
3. 手工旋转时 t 不动，中心间距离不变，显示方向、代理与拾取一致；反复修改再恢复同一配置无累积漂移。
4. 在校正前后分别创建贴合桌面的盒，再转向或改尺度，两者都保持相对桌面的姿态；新增远处盒不改变场景中心或归一化倍率。
5. 椅子掉落并变形后返回准备阶段，椅子回到源布局且无形变，速度清零；参与模拟选择、物性覆盖及手工盒仍在。重新校正后再模拟使用新世界几何。

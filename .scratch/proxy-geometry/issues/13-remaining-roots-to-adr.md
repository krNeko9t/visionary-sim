# 13 · §四 其余各根转成 ADR

Status: open
Type: grilling
Blocked by: 05

## Question

按 [ADR-0004](../../../docs/adr/0004-architecture-roots-become-adrs.md) 的判据，把 `ARCHITECTURE.md`
§四 剩下的 4.1、4.3、4.4、4.5、4.6 与「欠账」逐条转换，4.2 → ADR-0005 是样板。

每一条要回答：

1. **它够不够一条 ADR**（难以回退 / 无上下文会意外 / 真实取舍，三条都要）。不够的直接删，
   不硬凑一条 ADR。4.5 自称「没有逼出任何后果，孤立的一个根」，是第一个要过这道门的。
2. **哪些后果是跨模块、看得见的**（留在 ADR 里），哪些只对打开某个模块的人有用（核实它已在
   代码旁边，然后删）。核实是这张票的事实工作，不问使用者。
3. **「欠账」表放哪**。它跨里程碑存在，既不是选择也不是历史——可能是 ADR 的 Consequences，也
   可能是 issue tracker 里的票。
4. 转完之后 §四 的序言（「不分类」「按根决定排」）是否整段删除，`ARCHITECTURE.md` 开篇那句
   「§一到§三是不变的部分，§四是当前的选择」怎么改。

已知的一处：4.3 第一条「按最坏材料与**格子**选定 CFL」把点阵的词和「一个物体一个 `h`」的巧合
写进了求解器的根；03 已把它拆成 `cflLength`。

## 交付

- `ARCHITECTURE.md` 就地改，每个转换的根一条 ADR。
- 别的文件里「§四 4.x」的引用改指对应 ADR（`grep -rn "4\.[1-6]\|§四"`）；`src/` 里的注释引用
  受本图 `src/` 豁免约束，列出来交给使用者。

## Problem Statement

alocasia 是场景级扫描：植物、花盆与房间同在一份高斯点云中。需要把完整前景用于生成代理
几何，让叶片与叶柄可交互、clean 域内固定部分提供物理支撑。完整场景包含植物、花盆与房间：
clean 之外的盆身与房间只静态绘制，不提供材料、弹性支撑或代理接触。花盆和盆土的高斯位置
与形状保持静止，不要求完整花盆属于模拟源。

最初接入前只有一次交互持有的运动学规定，缺少属于物体的静态规定；抓取只排除无材料节点。
当前已完成前景组装、静态规定机制及 10 的背景接入。若将完整扫描作为模拟源，会把房间交给离散化。三个原始点云必须共用坐标变换，不能各自归一化；
米制尺度同时决定材料、抓取半径、区域容差与模拟精度的意义。

## 用户可见结果与范围

- `?scene=alocasia` 显示完整场景，包括植物、花盆及房间；场景重力为零，不绘制应用添加的玻璃缸。
- 拖叶片时叶柄随之弯曲，松手回弹并逐渐停下；固定高斯的中心、旋转和尺度保持不变。
- 静态节点不能作为抓取锚点，也不能被邻近叶片的握持球带走；射线跳过它们继续寻找可抓节点。
- 保留材质面板、抓取半径控制和代理几何线框视图，不提高每帧步数上限。
- 数据集专有知识留在场景与离线工具；核心只新增通用静态规定能力，不认识 PhysDreamer 文件。
- 另外三个 PhysDreamer 场景、逐点材料、学得的初速度/冲量、运行时锁定/解锁均不在本轮范围。

## 数据准备

### 输入与共同变换

输入为 `point_cloud.ply`、`clean_object_points.ply`、`moving_part_points.ply` 与
`transforms_train.json`。前者为场景高斯，后两者提供前景和可动部分的 xyz 样本；不把它们
当成可以按数组索引直接相减的三份高斯。

离线执行，顺序为核对 up、共同变换、前景/背景切分：

1. 用相机位姿的 up 方向核对声明的 +Z up，超过声明阈值则停止；没有位姿不能假称已核对。
2. 使用现有 z-up 到 y-up 的约定；以 clean 参考的转正后高度声明米制比例，高度沿用 0.30 m；它不是完整带盆植株高度。
   底部置于 y=0，水平方向居中。所有点云使用同一个变换，高斯旋转和尺度也相应变换。
3. 按高斯中心到 clean 样本的距离切分前景/背景。沿用旧 spec 的源坐标距离 0.01 作为待复核
   的前景切分声明；在米制坐标查询时同步换算。这个阈值与可动区域容差 `r` 是两个量。

产出完整前景高斯、变换后的可动 xyz 样本、背景高斯，放在 `public/splats/alocasia/`，产物
不进 git。运行时加载前景及背景，背景仅绘制。脚本可重跑且输出确定，打印实际应用的变换、up 偏角、尺度、
前景和房间尺寸、各点云数量；运行时不再摆放。

离线工具不进入运行时依赖。若实现新增目录，按仓库规则同步架构表和依赖护栏，变更依赖规则
须记录 ADR；不得以现有测试只扫描 `src/` 为由豁免新增目录规则。

## 固定区域与高斯分类

clean/moving 是 xyz 样本，不是可按索引相减的高斯集合。“clean − moving”表示 clean
映射所得前景内的固定区域；“point cloud 剩余”表示前景切分后的背景。先按 clean 距离切出
前景，再仅在前景高斯及该模拟源生成的节点上应用以下判据；背景不进入 moving 分类或代理生成。

令 `M` 为变换到共同静止世界空间的可动样本，`r` 为场景声明的米制距离容差：

- `movable(x) := distance(x, M) <= r`。
- `static(x) := distance(x, M) > r`。
- `r` 不依赖 `elementSize`、代理节点间距或 CFL 尺度。改变模拟精度时保持同一个区域。
- 高斯按中心整体归类，节点按静止位置归类；两者使用同一个判据、同一个 `r`。
  跨界高斯不拆分，不按椭球覆盖范围扩大判据。等于阈值时归可动。

距离查询是场景侧的纯逻辑，空间索引只用于加速，不能改变欧氏距离判据。不逐节点暴力扫描
全部可动样本；可使用场景侧空间桶。禁止从场景 import 点阵驻留区的内部工具（ADR-0014）。

### 数值校准门槛（07 已完成，保留证据限制）

`r` 必须通过真实资产核对后固定在场景声明，不能用旧 `h` 代填，也不能直接抄官方归一化
阈值。通用静态规定机制、合成测试与数据报告工具可先实现；alocasia 最终参数确定和真实
场景验收前必须完成校准。数据报告应给出候选米制容差、分类数量及固定节点占有质量节点的比例，并检查
clean 域内应固定的盆沿/盆土等材料确实分入固定前景、叶片与叶柄未被误固定。
clean 之外的盆身/盆土保持静态背景，不要求用 r 把它们找回前景。数量正常只是必要条件，不是语义验证。

用同一个 `r` 在不同 `elementSize` 下复查：高斯分类必须相同，节点是在同一世界区域上的
不同采样。若样本分布使任何合适的 `r` 都无法分开目标区域，报告证据并重开区域决定，不能
静默引入第二个半径、高度裁剪或语义修补。

### 退化处理

纯分类逻辑对空 `M` 返回全固定；核心允许空静态集合或全静态集合。
但 alocasia 必须同时存在可动材料和固定支撑：可动点为空、无有质量节点、无固定有质量节点
或全部有质量节点固定时，停止加载并报告原因、`r` 和各类数量，不继续作为成功场景展示。
无效/非有限坐标与容差应作为输入错误报告。静态比例越高可能意味着 `r` 太小，不是太大。

## 模拟与绘制的组装

沿用直接组装 `SoftBody` 的路径，不走会再次测量和摆放的 `loadCapture` / `splatBody`。
前景和背景使用同一清洗规则：保留 opacity >= 0.1 的高斯（现有 `cleanCloud` 默认值），
不得按层改变阈值或添加语义裁剪。分别清洗既有互斥产物等价于对全场景统一清洗；前景只
清洗一次供模拟与绘制共用，再按 r 分类。可动前景、固定前景、背景三层互斥且完整覆盖
清洗后保留的场景高斯；清洗剔除数单列，不算分类丢失。所有高斯属性同步保留。

| 用途 | 输入 |
|---|---|
| `SoftBody.source` | clean 映射所得、清洗后的完整前景；这是唯一模拟源，不包含背景盆身或房间 |
| `SoftBody.render` | 可动高斯子集，绑定该模拟体的形变场 |
| `scene.scenery` 固定前景 | 前景内固定高斯，不绑定形变场；对应材料有静态规定 |
| `scene.scenery` 背景 | 清洗后的背景高斯，不绑定形变场；无材料、节点、抓取资格或接触表面 |
| 区域判据 | 共同变换后的可动样本与场景米制 `r` |

可复用 `subsetCloud` 保持所有高斯属性同步，场景加载共享结果，避免两条入口重复读取和分类。
固定前景和背景均不安装形变 modifier，中心、旋转、尺度保持共同变换后的资产值。
空绘制子集（包括空背景）须显式跳过，不能假设零高斯资源天然可用。背景资产缺失、格式错误
或任一层加载失败须明确失败并回收资源，不能以缺层画面冒充成功；共享异步加载结果并正确销毁资源。

**已接受的取舍（ADR-0015，由 ADR-0019 修订范围）**：固定/可动交界处，代理形变与静态画面可能不完全重合，接缝
可能拉开或重叠。不冻结固定高斯的全部采样支撑，不为绘制静止额外固定可动侧材料。完整前景
仅在 clean 域内提供物理支撑与代理接触；背景盆身无碰撞支撑。静态绘制绝不代替静态规定，
也不承诺碰撞面与高斯精确重合。
当前没有同一模拟体内的自接触，不能承诺叶片绝不穿盆。

## 静态规定机制

采用 ADR-0016 的物体声明路径：

1. `SoftBody` 可选携带通用的静止世界空间区域判据，未声明时没有静态规定。它不接收节点
   索引，不认识点阵、可动点文件或 GPU。
2. 模拟侧构造/重建时，以代理交出的节点静止位置求静态节点集合；只把有材料节点计入固定
   材料统计。物体局部索引转换为共享状态索引由模拟侧完成。
3. `Particles` 独立保存静态集合与已有运动学集合，统一合成 GPU 逆质量。
   材料 `invMass` 保留原值；代理接口中零只表示无材料的规则不变（ADR-0003）。
4. 改密度重新合成质量；松手只清运动学集合；重置恢复静止位置和零速度并保留静态集合。
   节点重建后从物体声明重新求集合，不复用旧索引。
5. 不新增求解器派发约束。静态节点从初态起不参与位置求解；接触表面仍保留这些节点。

构造期的具体字段名与批量查询形状属于实现细节，但必须能用合成位置测试，不依赖真实数据
或 GPU。诊断需能向场景报告每体的有材料节点数、静态节点数和可动节点数，以落实退化检查。

### 抓取的一致性

拾取与握持物选择都按“有材料且非静态规定”过滤；不修改材料数组来冒充资格，也不能直接用
含运动学规定的 GPU 逆质量作为通用拾取资格。

- 射线跳过静态节点，在原有瞄准容差内继续寻找最前的合格节点。
- 握持球仍是同一物体内的固定米制半径；先排除静态节点，再按距离排序和容量截断。
- 保留单节点对照策略、最近优先截断与超容量警告；不扩大球来补足被排除的节点。
- 静态节点不得进入硬律或柔律的驱动集合；两种驱动核都会直接写位置，质量为零本身挡不住。

射线针对代理节点，不是高斯表面的精确拾取；点击盆沿图像时，附近或后方合格节点仍可能在
瞄准容差内被选中。“花盆不可抓”保证的是固定材料不会成为握持物，不增加可见表面遮挡测试。

## 场景参数与实时预算

- `Scene` 增加可选重力声明，由 `main.js` 在首次步进前传入模拟参数；alocasia 为 `[0,0,0]`。
  不声明的场景保留现有默认值，不新增重力 UI。
- `decorate` 不画玻璃缸；求解 bounds 仍依据前景包围盒外扩，底部 y=0，不因背景扩大物理域。
  观察须能检查完整场景及植株，相机裁剪不得意外省略背景；不能把观察范围直接变成求解范围。
- 初始 `elementSize` 约 0.016 m，替代旧 R=24 输入；材料从 `DEFAULT_MATERIAL` 起步：
  E=120000 Pa、密度 1000 kg/m³、泊松比 0.40。保留现有阻尼、松弛与材质 UI。
- 稳定步长依据实测 `cflLength`：`dt=min(1/240, 0.75/(c/cflLength))`，每帧最多 24 步。
  理想 60 Hz 的步数预算要求 `c/cflLength <= 1080 s⁻¹`；它不是设备帧率保证。
- 不调整 `MAX_STEPS_PER_FRAME` 或默认 0.03 m 抓取半径，不先行透传填充/封口参数。
  若叶片/叶柄被代理桥接或过度增厚，用真实几何与线框证据重开选择，不靠静默改 `r` 修复。

## 验收

### 合成数据与状态契约

- 距离内、外、恰在边界；空可动样本；输出确定。相同坐标在不同离散采样中归类相同，
  加密节点时不缩小 `r`；不用节点数相等冒充材料区域相同。
- 前景高斯中心与节点共用分类；两个前景子集与背景三层互斥且完整覆盖清洗后场景，属性一致。
- 背景与前景同变换对齐；背景不改变前景材料/节点统计，无物理/抓取资格。验证共享加载、
  空背景、资产失败及资源清理；分别报告前景切分、清洗剔除与三层数量。
- 固定前景与背景均不随模拟位置更新改变中心、旋转或尺度；可动高斯仍走既有形变绑定。
- 静态与运动学集合并存；松手、改密度、重置均不解除静态规定，不污染材料逆质量。
- 多体局部/全局索引正确；静态节点不参与拾取或球选，也不消耗握持容量。
- 硬、柔两种抓取下固定节点均保持静止；固定接触节点参与对其他物体的响应。
- 核心空/全静态集合合法；alocasia 的空可动点、无支撑、全固定会报告诊断并停止。
- 共同变换保持三份数据对齐；up 核对失败停止；重跑确定。距离查询用小规模暴力参考结果
  对照，不因为现有点阵工具有测试就免测新查询逻辑。

### 真实数据与 GPU

- 校准并记录米制 `r`、坐标变换、三层数量与边界证据；clean 内固定材料正确归类，
  背景盆身/盆土及房间完整可见并对齐。不得将背景静止当作其参与物理的证据。
- 拖动、松手、切换硬/柔抓取、改密度和重置后，固定前景、背景高斯和静态节点仍保持静止，叶片可动。
- 观察叶柄连接、薄结构及封口桥接。旧“体积占比超过三成即错误”没有足够依据，不作为硬阈值，
  场景也不得为此读取 `lattice.volume`。
- 在包含三层高斯完整绘制负载的目标设备上按 60 fps 验收预算：`cfl < 1`、每帧步数不超过 24、`droppedTime == 0`。
  报告实测设备和条件，不能用理论步数预算代替。
- `architecture.test.js`、`docs.test.js` 与相关行为测试通过；不放宽点阵知识边界。

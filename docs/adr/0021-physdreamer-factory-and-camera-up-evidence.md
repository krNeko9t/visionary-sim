# PhysDreamer 共用工厂，世界 up 与相机观察证据分开

Alocasia 的加载、三层绘制、材料标签延拓和离线变换提为 PhysDreamer 共享模块；场景只声明
名称、资产根、独立米制 r/elementSize、材料/抓取与是否要求固定材料，以及离线尺度和相机
观察判据。旧入口薄转发，运行时不依赖 Node/tools。扩展 ADR-0018 的具名离线入口为
`scene/physdreamerData.js` 与 `scene/physdreamerDeclarations.js`，替换 alocasia 专名入口；
代理、静态区域、材料计数入口不变。依赖护栏仍限定完整路径，不开放任意场景装配依赖。
全动是否合法是场景声明，runtime 与校准共用材料失败判据；空材料与无可动材料仍失败。

源世界 +Z 是资产声明，共同旋转 (x,z,-y) 把它变成模拟 +Y；相机局部 +Y 只说明图像方向。
Carnations 合法右手位姿 frame_00052 是强俯拍，原始 camera-up 角达到 91.699°。把原阈值
放宽到 92°会混淆观察俯仰与世界方向。保留 alocasia 的 `camera-up` 模式及 55°语义，另提供
`projected-world-up`：将源 +Z 投影到相机图像平面，与图像 +Y 比较，仅投影长度至少 0.5 的
帧提供方向证据（至少保留一半单位 up 的图像分量，避免近光轴方向失稳）。有效帧全部必须
满足声明阈值，不能按角度超标排除；没有有效帧则失败。所有帧先验证有限、齐次、正交且右手，
全部原始偏角与投影角、长度、有效性和不确定原因保留在报告。投影模式阈值同样小于 90°，
倒置或明显滚转不能靠强俯拍的阈值穿过检查。

这只是声明坐标与观察姿态的相容证据，不是恢复或测量重力。Carnations 有 7/209 帧不确定，
有效帧最大投影角仍达 50.888°；即使其场景票经原图复核选择 55°，也不能宣称全部帧证明竖直。
Hat/telephone 的阈值与原图核对归各自票。本票只读复核统计，不提前批准新场景 r 或注册入口。
不采用一个全场景宽阈值，也不引入额外世界轴、逐帧例外或旋转拟合配置。

# 代理几何这道缝买的是局部性，不是可替换性

`ProxyGeometry` 这道缝（点阵拆成中立接口 + 住在 `sim/discretize/lattice/` 的 `VoxelLattice`）不是
为了「将来接第二个后端」而立的。第二个后端今天不存在，四面体网格只是用来撞出耦合的反事实。立它
的判据是：「换掉点阵要动什么」这句话能不能变成**真话**、能不能由护栏**机器检查**——也就是点阵的
知识能不能只待在一个目录里（离散化词表测试：只有 `sim/discretize/lattice/` 可以说点阵的词）。

## Considered Options

- **按可替换性立缝**：第二个后端出现时再抽接口，今天只有一个实现，抽了就是投机。否掉：它解释
  不了线框调试视图。那个视图当初完全可以是一条只认形变通道的渲染路径——离散化词表抓不到
  `deformationAt`，也抓不到 `deformedNode`——它之所以直接读 `lattice.cells`，不是分层规则逼的，
  是因为**直接读是免费的**。只要点阵的字段对外可见，这种伸手就会不断出现，与有没有第二个实现
  无关。

## Consequences

- 判断一处伸手该不该收，问的是「它是不是让点阵的知识离开了那个目录」，不问「第二个后端会不会
  用到它」。
- `corners.js`（立方体八角的偏移表）住在 `deformation/` 里不是一个放错位置的常量，是「通道与
  一个实现合住」的症状：通道本来只该持有契约。它随采样器搬进 `sim/discretize/lattice/`。
- 接口里 `spacing` 与 `cflLength` 分成两条，是这个判据的直接产物：两者在点阵上都读作 `h` 只是
  均匀网格的巧合，合成一个数就等于把点阵的知识写进了接口。

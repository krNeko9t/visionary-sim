# 离线工具单向复用资产入口与场景距离判据

离线数据准备放在仓库根 `tools/`，不进入 `src/` 运行时树。它可以读取 `assets/`
的 PLY/高斯编码与坐标约定，并复用 `scene/metricRegion.js` 的米制距离查询；不允许
读取场景的其他模块或模拟内部实现。运行时代码不能反向引用 tools 或 Node 内建模块。

依赖表新增 `../tools`（相对 src）；架构与文档护栏同时扫描该目录，新增子目录也须登记。
采用单向依赖避免另写一份离线距离算法，使前景离线切分与场景区域使用同一已验证判据。
不把 Node 文件读写放进运行时资产入口，也不因原护栏仅扫描 src 而豁免离线代码。

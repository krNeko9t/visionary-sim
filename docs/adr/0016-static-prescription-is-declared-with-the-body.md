# 静态规定的区域随物体声明，在模拟构造时离散化

静态规定归属于物体（ADR-0002）。世界空间区域判据随 `SoftBody` 声明，模拟侧在构造或重建时
按节点静止位置求出静态集合；物体本身不认识节点或代理几何实现。改密度、抓取松手与重置均
保留这项声明，本次不提供运行时锁定或解锁。

不采用构造模拟器后由应用层再配置区域的入口：那会把物体与它的区域声明分开维护，并要求
重建时重新应用。也不新增求解器派发约束：这里的自由度从静止初态起就不参与求解，没有逐步
更新的目标。静态集合与运动学规定分别保存，再合成 GPU 逆质量，继续遵守 ADR-0003。

PhysDreamer 的可动点、距离查询和容差留在场景侧；核心接收通用区域判据，不认识数据集文件。

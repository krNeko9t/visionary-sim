# 完整场景包含仅绘制背景，物理域仍由 clean 定义

用户于 2026-09-22 明确 moving 区域可动、clean 中其余材料固定、point cloud 剩余仅绘制，
最终显示完整场景。真实数据已证明完整盆身存在于 background 产物，而不在 clean 对应前景。
本决定取代 ADR-0015 中“不加载背景”及“完整花盆必属模拟源”的范围假设：clean 映射所得的
完整前景仍为唯一模拟源，其中可动高斯绑定形变、固定前景静态绘制；背景盆身与房间同变换
静态绘制，不加入物理域。clean/moving 是样本，集合关系经距离映射解释，不按数组索引相减。

不重标 clean 或扩大前景阈值来补齐物理盆身：这会改变用户指定的材料边界，还可能引入桌面。
也不继续省略背景，否则完整场景不可见。三层采用同一 opacity 清洗规则，互斥覆盖保留高斯；
背景静止不代表它有材料、弹性支撑、代理接触或抓取资格。观察范围须容纳场景，求解范围仍由
前景决定，完整背景的绘制负载须进入实际性能验收。

保留 ADR-0015 的前景模拟源与静态绘制分离及接缝误差取舍，保留 ADR-0016 的物体静态区域
声明。背景盆身无碰撞支撑，也没有由此新增自接触或叶片不穿盆的保证。0.30 m 保持原 clean
范围高度；真实 r 尚待校准，60° up 阈值仅为探索声明，本决定不批准数值参数。

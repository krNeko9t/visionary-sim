# 代理几何是均匀体素点阵，每格按 Kuhn 切六个四面体

代理几何用规则点阵，不用无结构四面体网格。选它是因为体素是 3D 空间里最简单的一种表示，当时
没有比较过别的方案。简单事后兑现成了具体收益：三种来源（解析形状、三角网格、高斯点云）都先
变成占据栅格再走同一条路，不需要四面体网格生成器——点云本来就没有可以交给生成器的表面；而
规则性让节点寻址、单元分批与静止形状都成了算术，不占缓冲区。

## Consequences

只列跨模块、在屏幕上看得见的后果；其余的写在逼出它们的代码旁边。

- **接触发生在点阵分辨率上**：两个静止物体之间约留一格的缝，那是粒度，不是求解器误差（推导在
  `sim/constraints/bodyContact.js`）。`sim/grip.js` 为此不让抓取球跨物体。
- **点阵必须把渲染表面整个包住**：差一格不是位置略偏，是黑斑——那个格子有角点没有质量、永远
  不动（填充规则在 `sim/discretize/voxelize.js`）。
- **薄结构被印成一格厚**：画出来仍然是薄的，但弯曲刚度按一格的厚度算，要显得会摆，杨氏模量
  得比真实材料低得多。

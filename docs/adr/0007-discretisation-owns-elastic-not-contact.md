# 离散化自己交出弹性约束，接触约束不由它交出

代理几何的每种实现自己造出弹性约束交给求解器（`elasticConstraints()`），但接触约束仍是一份跨所有
物体共用的 `BodyContact`，代理几何只交出接触需要的表面数据。这个不对称是故意的，判据只有一个：
**约束是否跨物体耦合。**

弹性从不跨物体耦合。把不同物体的同批单元塞进同一次 dispatch 只是**共址**，靠的是物体拥有不相交的
节点区间，不是耦合，所以每种离散化各管各的弹性不会漏掉什么。接触跨物体：窄相必须同时看见两个
物体的表面，粗筛是一张世界空间的共用网格。若每种代理几何各自带一份接触约束，混合场景里就会有
两张互相看不见对方的粗筛网格，**不同种类物体之间的接触当场消失**。

## Considered Options

- **两者都由离散化交出**（形式上对称）。否掉：见上，跨种类接触消失。
- **两者都留在 `sim/constraints/`，离散化只交中立的单元表**（原先的中立 `ElasticCells`）。否掉：
  单元表、批次规则、每单元静止形状全是实现的知识，中立的单元表不存在——点阵的单元是「格 +
  六个 Kuhn 四面体」，别的实现连单元是什么都不一样。

## Consequences

- 离散化实现要能看见求解器的公式（XPBD 顺服量、本构投影），于是依赖方向翻转：`sim/discretize`
  可以依赖 `sim/state`、`sim/constraints`、`body`，`sim/constraints` 不再依赖 `sim/discretize`。
  依赖表在重构的对应一步里改，理由另写一条 ADR。
- 看到这个不对称想「统一一下」的人，先读这一条。

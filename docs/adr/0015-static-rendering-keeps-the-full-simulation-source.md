# 固定高斯静态绘制，模拟源仍保留完整前景

alocasia 要求花盆和盆土的高斯位置、形状严格静止。固定区域由可动点样本与独立的米制距离
容差定义，不随模拟单元尺寸改变；但只固定区域内的节点不能保证边界高斯静止，因为位置和
形变梯度可能依赖可动侧节点。因此完整前景保留为模拟源，可动高斯随形变绘制，固定高斯走
已有的静态绘制路径。高斯按中心与节点共用同一个距离判据：距离不超过容差为可动，超过为
固定；跨界高斯整体归类，不按椭球范围扩展，也不拆分。具体容差由场景数据校准。

不采用冻结固定高斯全部采样支撑的方案：它会额外固定可动侧材料，让盆沿附近叶柄的可动范围
随离散化尺寸缩小。分开绘制保留了原定的节点区域判据，也无需向场景暴露采样器内部结构。

代价是固定/可动交界处，近似代理的形变与静态绘制可能不重合，接缝可能拉开或重叠。静态绘制
不能替代物理侧的静态规定；完整模拟源中的花盆仍提供材料、弹性支撑及代理接触表面。
静态绘制路径承载固定前景不意味着本轮也要加载房间背景。

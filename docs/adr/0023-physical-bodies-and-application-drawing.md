# 模拟体只描述物理，应用按构造位置配对绘制

模拟体携带绘制对象会使只收内存数据的内核认识宿主外观；让静止几何类型住在加载器里，即使只引用类型也会带入应用依赖。因此三角网格、解析形状和高斯云的静止几何类型及求解所需纯函数归内核 `body/restGeometry.js`；加载、解码、清洗、摆放、单位换算、形状生成、绘制表面、颜色和资产报告归应用。`sim` 与离散化不再依赖 `assets`，应用 `assets` 可引用中立的静止几何，`body/factory.js` 负责组装。

应用场景返回 `{ body, render, tint, report }` 列表，只把 `body` 列表交给模拟器；绘制对象与代理线框使用同一构造位置的形变场，不按名字寻址，也不因绘制为空而过滤物理输入。固定前景仍保留在完整模拟源中并受静态规定，仅绘制背景继续不进入物理；静态绘制不改变材料归属。所有静止几何已在同一个以米为单位的世界中，无逐体变换。此次保留高斯旋转/尺度输入与原数组数值，协方差输入另行处理。

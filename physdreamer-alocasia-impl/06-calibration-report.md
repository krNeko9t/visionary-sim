# 06: 为米制容差校准生成分类、支撑与精度对照报告

**What to build:** 对共同变换后的资产运行一条可复查的报告流程，比较候选米制 r 在不同模拟精度下的高斯分类与有材料节点分类，并提供核查花盆、盆土、叶片、叶柄的边界证据材料。

**Blocked by:** 05 — alocasia 场景组装（复用同一清洗、分类和每体统计路径）。

**Status:** resolved

- [x] 显式输入一组候选米制 r 与至少两档 elementSize；报告输入标识、变换声明、清洗前后数量、可动/固定高斯数、有材料/静态/可动节点数以及固定有质量节点比例。
- [x] 同一个 r 在各档精度保持不变，验证高斯分类完全相同；节点解释为同一世界区域的不同采样，不用节点数量相等冒充区域一致。r 不从旧 h、节点间距或官方归一化阈值推导。
- [x] 输出可供实际检查的分类/边界证据，例如带分类标记的可视化数据或可重复查看方式，使花盆/盆土是否固定、叶片/叶柄是否误固定可核查；单纯总数不能构成语义校准结论。
- [x] 报告全部退化情况、无效输入、候选 r 与原因；说明固定比例升高可能来自 r 太小。候选无法分离目标时保留证据，不能引入第二个半径、高度裁剪或语义修补。
- [x] 合成资产端到端验证报告的数值、确定性、精度对照与失败案例，报告明确标记合成输入。记录执行方法及测试结果；不要求真实资产或 GPU 才能完成本票。
- [x] 保持离线工具与运行时依赖分离，不读取点阵内部体积或 import 内部工具；新增代码目录和依赖变更遵守架构、护栏与 ADR 规则。

## 实施边界

依据原 spec「数值校准门槛」及真实验收的数据报告要求。此票交付校准工具，不自动选择或宣布真实 r 合格。真实语义检查与参数落定在 07。

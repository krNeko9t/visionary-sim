# 04: 离线核对坐标并确定地产出共同米制前景、可动样本与背景

**What to build:** 一条可重跑的离线命令读取场景高斯、clean xyz、moving xyz 与相机位姿，核对 up 后以唯一共同变换产生运行时资产和可审计报告。

**Blocked by:** 03 — 用同一个米制距离区域分类高斯中心与节点（复用已验证距离查询）。

**Status:** ready-for-agent

- [ ] 输入为 point_cloud.ply、clean_object_points.ply、moving_part_points.ply、transforms_train.json。两份样本只按 xyz 处理，不要求有高斯字段或相同数组索引，不以数组相减分类。
- [ ] 使用相机位姿 up 核对声明的 +Z up，角度阈值显式声明并报告；缺位姿、格式/坐标无效或偏角超过阈值停止，不假称已核对。说明实际采用的相机坐标约定与 up 推导。
- [ ] 沿用 z-up 到 y-up 约定，以转正后的 clean 前景参考高度声明 0.30 m 比例，底部 y=0、水平居中；所有点云共用同一旋转、比例与平移，高斯旋转和尺度同步变换。不得分别归一化或按最长轴替代高度。
- [ ] 共同变换后按高斯中心到 clean 样本距离切分前景/背景；声明源坐标 0.01 阈值并换算为米制，明确它与可动 r 不同且待真实复核。
- [ ] 完整前景高斯、变换后的可动 xyz、背景高斯产出到 public/splats/alocasia/，产物不入 git。输出格式与读取约定可由运行时消费，运行时无需再摆放；保留所有需要的高斯属性。
- [ ] 打印实际变换、up 偏角/阈值、米制尺度、前景/房间尺寸及各输入输出数量，重跑确定。异常失败不能留下可误用为成功资产的结果。
- [ ] 以临时合成 PLY/位姿做真实 CLI 往返测试，覆盖对齐、旋转/尺度、距离换算、背景分离、缺位姿/up 失败和重复执行确定性；记录命令、输出与测试结果，合成数据不冒充真实资产。
- [ ] 离线依赖不进入运行时。新增工具代码目录时同步架构目录表、依赖护栏及必要 ADR，不以现有护栏只扫描 src 为由豁免；相关护栏和 build 通过。

## 实施边界

依据原 spec「数据准备」。本票不依赖真实资产到位，可用合成输入完整验收工具；真实变换及前景阈值核对在 07。原始数据不得伪造，历史数量和尺寸不是本轮测量。

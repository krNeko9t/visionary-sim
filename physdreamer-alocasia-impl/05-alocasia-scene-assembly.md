# 05: 接通 alocasia 的零重力模拟与固定高斯静态绘制

**What to build:** 场景入口加载已共同变换的前景与可动样本，在有效已声明 r 下组装完整模拟源、可动绘制和固定绘制；无效分类停止加载并清楚解释。全部路径先用合成资产验证。

**Blocked by:** 01 — 静态规定；02 — 静态安全抓取；03 — 米制区域分类；04 — 离线共同变换产物。

**Status:** ready-for-agent

- [ ] 注册 ?scene=alocasia，共享一次资产加载、统一清洗与分类结果供物体和 scenery 使用。直接组装 SoftBody，完整清洗前景作为 source，可动子集作为 render，固定子集走 scenery；不走会重新摆放的捕获/物体工厂路径，不加载房间背景。
- [ ] 固定高斯不安装形变 modifier；位置、旋转、尺度保持资产值。可动高斯走既有形变绑定，空绘制子集显式跳过，不创建零高斯资源；合成测试实际验证绑定选择与属性不变。
- [ ] 静态区域判据随物体声明；场景对空可动样本、无有质量节点、无固定有质量节点或全固定有质量节点停止加载，并报告原因、r 与分类数量。模拟构造后所需统计通过中立公开接口取得，不能让退化场景启动步进或以部分画面冒充成功。
- [ ] Scene 支持可选重力声明，首次步进前传入模拟参数；alocasia 为 [0,0,0]，未声明场景保留默认值。新增配置不引入重力 UI。
- [ ] 不绘制玻璃缸，观察/求解 bounds 从完整前景包围盒外扩、底部 y=0；正确安排异步准备时序，确保相机和求解器收到最终 bounds。
- [ ] 初始 elementSize 约 0.016 m、材料从默认 E=120000 Pa、密度 1000 kg/m³、泊松比 0.40 起步；保持阻尼/松弛、材质面板、抓取半径与代理线框。稳定 dt 继续由实测 cflLength 给出 min(1/240, 0.75/(c/cflLength))，24 步上限与 0.03 m 默认抓取半径不变。
- [ ] 生产场景不得以旧 h、官方归一化阈值或任意占位数冒充已校准 r。07 未完成时明确拒绝以未校准配置宣称就绪；合成测试通过显式测试声明验证完整成功路径及失败路径。
- [ ] 记录合成加载/渲染/重力首次步进/退化处理的行为测试证据；现有场景回归、架构/文档检查和 build 通过。必要结构文档与依赖 ADR 同步。

## 实施边界

依据原 spec「用户可见结果」「模拟与绘制的组装」「退化处理」「场景参数与实时预算」。接受 ADR-0015 的接缝误差；不额外冻结可动侧材料、不透传填充封口参数、不承诺叶片不穿盆。真实参数由 07 解锁，真实 GPU 验收由 08 完成。

# 02: 抓取叶片时跳过静态材料，并保护两种驱动律

**What to build:** 射线能越过静态节点找到合格节点；握持球仅带走同一物体内可动材料，硬律、柔律与切换都不能拖走静态支撑。

**Blocked by:** 01 — 让模拟体声明静态区域，并在完整状态生命周期中保持固定。

**Status:** resolved

- [x] 拾取和所有握持物策略共同遵守“有材料且非静态规定”。不篡改材料数组，不用包含运动学规定的 GPU 逆质量充当拾取资格；已有运动学规定不能被误当成静态材料。
- [x] 射线保持原瞄准容差，跳过静态节点后继续寻找最前合格节点；不增加高斯表面遮挡测试。
- [x] 握持球保持同体、固定米制半径；先过滤静态节点，再按距离排序和容量截断。静态节点不计 found/容量，不扩大球补足节点，保留最近优先、确定性平局、超容量警告与单节点对照策略。
- [x] 从公开抓取入口到硬/柔驱动集合均验证静态节点不进入；驱动直接写位置，不能以逆质量为零作为保护。切换驱动、松手、改密度与重置保持 01 的集合语义。
- [x] 合成测试覆盖前方静态/后方可动、混合握持球、跨体边界、容量截断、全静态未命中、单节点策略，以及硬/柔驱动实际收到的节点。记录相关测试与架构、文档检查证据。

## 实施边界

依据原 spec「抓取的一致性」。默认抓取半径仍为 0.03 m，保留现有抓取半径 UI；不改变“射线对代理节点拾取”的含义。真实交互位置与画面证据由 08 完成。

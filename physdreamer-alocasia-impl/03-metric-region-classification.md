# 03: 用同一个米制距离区域分类高斯中心与节点

**What to build:** 场景可将任意静止世界位置一致地归为可动或固定，并把一次清洗后的完整前景拆成互斥且完整的绘制子集，为模拟体提供同一个静态区域判据。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 场景侧纯逻辑以到可动 xyz 样本集合的欧氏最近距离判定：小于或等于 r 为可动，大于 r 为固定；空样本集合返回全固定。无效/非有限样本、查询坐标或容差明确报输入错误，负容差拒绝，零容差边界定义清楚。
- [ ] 查询采用适当空间索引而非对每个节点扫描全部样本；只加速、不近似改变判据，不 import 点阵驻留区内部工具。
- [ ] r 与 elementSize、节点间距和 CFL 无关；同一坐标在不同采样中分类相同。高斯按中心整体归类，不拆跨界高斯，也不以椭球范围扩张判据。
- [ ] 一次清洗后的完整前景按同一结果生成可动与固定子集，保留所有高斯属性的对应关系；两个子集互斥且完整覆盖输入。可以复用已有 subsetCloud。
- [ ] 用小规模暴力最近距离参考对照索引结果，覆盖边界、空集、重复点、桶边缘、负坐标、输入排列和重跑确定性；覆盖不同离散采样以及全部属性同步与空子集。
- [ ] 测试不依赖真实资产/GPU；记录命令和结果，架构与文档护栏通过。不得先填未经校准的 alocasia r。

## 实施边界

依据原 spec「固定区域与高斯分类」「模拟与绘制的组装」及 ADR-0014/0015。此票只提供可复用的场景分类与拆分行为；具体加载、模拟和绘制在 05 接通。

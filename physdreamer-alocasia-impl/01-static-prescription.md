# 01: 让模拟体声明静态区域，并在完整状态生命周期中保持固定

**What to build:** 作者可为模拟体声明通用的静止世界空间区域。模拟构造时，该区域内节点从初态起不参与位置求解，同时继续作为材料和接触表面存在；未声明的物体保持现状。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 遵守 ADR-0003/0016：物体只声明区域判据，不接收节点索引，不认识 GPU、点阵或数据集；模拟侧对代理静止位置求集合，并负责多体局部到共享索引转换。纯位置与模拟构造测试不依赖真实资产或 GPU。
- [ ] 状态独立保存静态集合与运动学集合，GPU 逆质量由材料逆质量与二者合成，第一份上传即已生效。材料逆质量和代理中零代表无材料的契约不变，不新增求解器派发约束或运行时锁定/解锁功能。
- [ ] 松手只释放运动学规定；改密度重新合成质量；重置恢复静止位置与零速度且保持静态规定；重新构造以新节点静止位置重求集合，不复用旧索引。
- [ ] 核心允许空/全静态集合。每体可报告有材料、静态有材料、可动有材料节点数量；无材料节点不计入固定材料统计。统计不泄漏代理实现细节。
- [ ] 静态接触节点仍存在于接触表面，合成双体案例验证静态侧不移动、另一物体仍获得接触响应；不能仅以 GPU 逆质量为零替代接触验证。
- [ ] 提供合成多体/非零偏移、空/全静态、静态与运动学重叠、密度/松手/重置/重建的行为证据。相关测试及架构、文档护栏通过，记录执行命令与结果；真实 GPU 位置验证由 08 完成。

## 实施边界

依据原 spec「静态规定机制」「合成数据与状态契约」。本票交付静态支撑与状态生命周期；02 完成两种交互驱动的资格过滤，不能在此票完成时宣称交互验收通过。必要结构变化同步当前架构与护栏，依赖规则变化记录 ADR，保留点阵知识边界。
